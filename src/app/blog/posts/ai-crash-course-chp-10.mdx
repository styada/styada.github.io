All right. Enough theory. Let's get your hands on this.

By now you've read about LLMs, image generation, video, and ethics. You might be curious. You might be skeptical. You might think "okay, but how do I actually *use* this stuff?" This chapter is for that.

## Choosing Your First Tool

The barrier to entry is low. You don't need to code. You don't need expensive hardware. You can start today, for free.

**For text generation:** ChatGPT, Claude, Gemini, or Perplexity. If you want free with ads, Perplexity works. If you want more capability and don't mind paying a few dollars a month, ChatGPT+ gives you access to GPT-4 and plugins. Claude offers a free tier and has a reputation for thoughtful, nuanced responses. Gemini (Google) is free if you have a Google account.

Start with one. They're all conversational AI, so the interface is familiar — you type, it responds.

**For image generation:** Stable Diffusion (free via Hugging Face or other interfaces), DALL-E (paid credits), or Midjourney (Discord-based, paid). If you want zero friction and free, Stable Diffusion via a web interface is your move. If you want polished results, DALL-E is worth a few dollars.

**For video generation:** Runway ML or Pika. Both let you generate short video clips. Both are accessible through web interfaces. Both have free trials.

**For audio:** Play with Eleven Labs for voice synthesis, or Mubert for background music.

Don't stress about choosing perfectly. You can try multiple. They all work similarly enough that learning one helps with the others.

## Step-by-Step: Your First Conversation with ChatGPT

Open ChatGPT. You'll see a text box. Type something. Let's try:

```
Write a short scene where a software engineer explains their job to a five-year-old. Make it funny.
```

Hit enter. Wait a few seconds. You'll get a response. It might be good. It might be weird. Either way, you just used an LLM.

Now try a follow-up:

```
Make it shorter and add a joke about bugs.
```

The AI remembers the previous message and refines. This is the power of conversational interaction — you're not starting over each time; you're iterating.

Try a few more experiments:

- Ask it to explain something you don't understand
- Ask it to brainstorm ideas for something
- Ask it to help you write an email you find hard to write
- Ask it to generate something creative (a poem, a song, a story)

Notice what works and what doesn't. Notice where it's helpful and where it's confidently wrong. This experiential learning is more valuable than any manual.

## Step-by-Step: Your First Image

Open an image generator. If you're using Stable Diffusion via Hugging Face, the interface is simple. Text box. Hit generate. Wait.

Try a basic prompt:

```
A cozy cabin in the mountains during autumn, digital art
```

You'll get an image. Probably four of them. Look at them. Are they what you imagined? Not quite?

Iterate:

```
A cozy cabin in the mountains during autumn, digital art, by Bob Ross, warm colors, oil painting style
```

Notice what changed. Adding artist style and medium helps. Try again with different modifications. What happens if you add "cinematic lighting"? Or "hyperrealistic"? Or "minimalist"?

This iterative process teaches you how language maps to visual output better than any explanation.

## Getting Better Results

A few patterns emerge once you start experimenting:

**Be specific.** "A forest" is vague. "A dense rainforest with tall trees, mist, shafts of light, hyperrealistic, shot with a telephoto lens" is specific. Specific prompts get better results.

**Use style references.** "In the style of Miyazaki" or "like a photograph by Annie Leibovitz" or "pixel art" — these help guide the output.

**Mention medium.** "Oil painting," "digital art," "photograph," "sketch" — these matter. The model generates differently based on the medium.

**Use negative prompts.** Many image generators let you say what you *don't* want. "Deformed hands," "text," "low quality." This helps avoid common failure modes.

**Iterate and compare.** Generate multiple versions. Which one is closest? What would make it better? Refine and try again.

**Use tools together.** Ask an LLM to help you write better prompts for an image generator. Ask an image generator to help you visualize something you're describing in words. Different tools complement each other.

## Common Pitfalls

**Trusting facts uncritically.** LLMs sound confident about things they're wrong about. If it's important, verify.

**Expecting perfection.** The output is a starting point. Editing, refining, and human judgment are still necessary.

**Getting frustrated with failures.** These tools fail in weird ways sometimes. It's part of the process. Try a different prompt.

**Assuming your prompts need to be complex.** Sometimes simple works better. Experiment with both.

**Using the tool for everything.** Not everything needs AI. Sometimes a simple solution is better. Use these tools when they genuinely add value, not just because they're novel.

## Best Practices for Getting Value

**Start with a clear goal.** What are you trying to accomplish? Brainstorm? Draft? Illustrate? Different goals benefit from different approaches.

**Use as a collaborator, not an oracle.** You bring judgment. The tool brings speed and generation capability. Together, you're better than either alone.

**Save your good prompts and outputs.** Build a library. Notice patterns in what works.

**Experiment in low-stakes contexts first.** If you're using these for work or something important, practice first in a sandbox. Play with them personally before deploying them professionally.

**Combine with other tools.** Prompts from LLMs can feed into image generators. Generated images can seed more generation. Video editors can assemble AI-generated clips. Think of these as building blocks in a larger workflow.

## Real-World Use Cases I've Seen Work

**Content creators** use LLMs to draft ideas, outlines, and scripts, then edit heavily. They use image generators to create placeholder visuals quickly.

**Designers** use image generators to explore ideas visually without committing time to a full mockup.

**Students** use LLMs to brainstorm essay ideas, check their understanding of concepts, and get feedback on their thinking. (Not to write essays for them, but as a learning tool.)

**Programmers** use code completion and LLMs to handle boilerplate and suggest implementations for well-known patterns. They still write the core logic themselves.

**Small business owners** use LLMs to draft marketing copy, social media posts, and customer communications. They save time on routine writing.

In each case, the human isn't replaced. The human's productivity and capability are expanded.

## What Not to Do

**Don't plagiarize.** If an LLM generates text you publish, that needs to be disclosed or rewritten enough that it's genuinely your work.

**Don't submit private data.** Don't paste your personal information, passwords, confidential documents, or anything you wouldn't want to leak.

**Don't use for high-stakes decisions without review.** If the output affects someone's life (hiring, medical, legal), humans need to review and verify.

**Don't assume bias doesn't exist.** Test if the tool works fairly for different groups if it's being used for something important.

## Your Next Step

Pick a tool. Spend 30 minutes playing with it. Try a few prompts. Generate something. Refine it. See what happens when you push it.

Don't worry about optimizing or doing it "right." Just experience it. Develop an intuition for how these tools work through experimentation rather than reading.

The best learning is doing.
